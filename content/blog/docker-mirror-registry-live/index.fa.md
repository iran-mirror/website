## آینه Docker فعال است

ما خوشحال هستیم که اعلام کنیم که رجیستری آینه **Docker Hub** ما اکنون فعال و آماده استفاده است.

**آدرس:** `docker.repo.mirrory.ir`

از امروز، می‌توانید تصاویر Docker را مستقیماً از زیرساخت مستقر در ایران با سرعت کامل بکشید، بدون timeout شبکه و با کش‌های بسیار سریع‌تر.

### آنچه در دسترس است

آینه Docker ما دسترسی به موارد زیر را فراهم می‌کند:

- **تصاویر کتابخانه رسمی** — nginx، postgres، redis، ubuntu، python، node و غیره
- **ناشران تأیید‌شده** — MongoDB، MySQL، Kubernetes، پروژه‌های CNCF
- **تصاویر جامعه** — میلیون‌ها تصویر نگهدارندگان توسعه‌دهنده از جامعه Docker
- **به‌روزرسانی‌های خودکار** — تصاویر جدید در دقایق پس از انتشار upstream کش می‌شوند

این را Docker Hub می‌دانید، اما سریع. هر تصویری از رجیستری Docker Hub رسمی بدون انتظار برای لینک‌های کند بین‌المللی در دسترس است.

### شروع سریع

به جای Docker Hub، یک تصویر را از آینه ما بکشید:

**از Docker Hub (کند):**
```bash
docker pull nginx:latest
```

**از آینه ما (سریع):**
```bash
docker pull docker.repo.mirrory.ir/library/nginx:latest
```

برای تصاویر جامعه، فقط `docker.io` را با `docker.repo.mirrory.ir` جایگزین کنید:

```bash
# قبل
docker pull myrepo/myimage:tag

# بعد
docker pull docker.repo.mirrory.ir/myrepo/myimage:tag
```

### گزینه‌های انضمام

**گزینه 1: برای هر تصویر (دستی)**
```bash
docker pull docker.repo.mirrory.ir/library/nginx:latest
```

**گزینه 2: پیکربندی daemon Docker (پایدار)**
`/etc/docker/daemon.json` را ویرایش کنید:
```json
{
  "registry-mirrors": ["http://docker.repo.mirrory.ir"]
}
```
سپس Docker را دوباره شروع کنید و تمام کش‌های خودکار از آینه ما استفاده می‌کنند.

**گزینه 3: Kubernetes (سطح خوشه)**
پرچم `--registry-mirrors` kubelet یا استفاده از یک کش pull-through در خوشه خود را پیکربندی کنید.

برای دستورالعمل‌های راه‌اندازی مفصل در سراسر پلتفرم‌ها [پیکربندی Docker برای استفاده از آینه‌های ما](/docs/guides/docker-mirror-setup/) را ببینید.

### چرا اهمیت دارد

کش‌های Docker Hub از ایران همیشه کند بوده‌اند. لینک‌های بین‌المللی، محدود‌کردن نرخ و شلوغی شبکه معنی‌اش:

- یک تصویر 100MB می‌تواند 10+ دقیقه طول بکشد
- خطوط لوله CI/CD با timeout ناموفق بوده‌اند
- تیم‌ها به جای کش‌کردن تصاویر تازه، تصاویر قدیمی را به صورت محلی کش می‌کردند
- توسعه با مسائل زیرساخت، نه کد، کند شد

آینه Docker ما این را تغییر می‌دهد. اکنون:

- کش‌های ثانیه‌ای هستند، دقیقه نیست
- CI/CD قابل‌اعتماد و سریع است
- شما همیشه آخرین تصاویر را دریافت می‌کنید
- توسعه بدون وقفه جریان می‌یابد

### آنچه کش می‌شود

ما کتابخانه Docker Hub کامل را آینه‌سازی می‌کنیم:

- کتابخانه رسمی (ubuntu، alpine، nginx، postgres، python، node، golang و غیره)
- ناشران تأیید‌شده و تصاویر رسمی
- تصاویر جامعه (محبوب و نیچ)
- تمام معماری‌ها (amd64، arm64، arm/v7 و غیره)

**تصاویر جدید به طور خودکار کش می‌شوند** — اگر یک تصویر هنوز در کش ما وجود ندارد، آن را از Docker Hub می‌بریم و برای کاربر بعدی کش می‌کنیم.

### کارایی

آزمایش اولیه نشان می‌دهد:

- میانگین کش زمان: **30-60 ثانیه** برای تصاویر معمولی (در مقابل 5-10 دقیقه از Docker Hub)
- Uptime: **99.9%+** — پایش‌شده و نگهداری‌شده 24/7
- Bandwidth: نامحدود — بدون محدود‌کردن نرخ هر تصویر یا کاربر

### قابل‌اعتماد

ما رجیستری خود را دائماً پایش می‌کنیم. اگر یک تصویر خراب یا فرسوده است، آن را از کش پاک می‌کنیم و یک کپی تازه بکشیم. شما همیشه آنچه را Docker Hub منتشر کرده است دریافت می‌کنید.

### آنچه بعد می‌آید

ما قبل‌اً در حال کار روی موارد زیر هستیم:

- رجیستری‌های اضافی (GHCR، ECR، GCR به زودی)
- آینه‌های منطقه‌ای برای ISP‌های ایرانی مختلف
- تجزیه و تحلیل پیشرفته و آمار استفاده
- بهینه‌سازی کارایی بر اساس الگوی استفاده

### بازخور دهید

Bug یافتید؟ کش کند؟ تصویر گم شده؟ [یک مسئله را در GitHub باز کنید](https://github.com/iran-mirror/mirrory/issues) و به ما بگویید. ما هر گزارش را می‌خوانیم و از بازخور شما برای بهبود استفاده می‌کنیم.

### اکنون شروع کنید

1. **روش انضمام خود را انتخاب کنید** — برای هر تصویر، پیکربندی daemon، یا Kubernetes
2. **یک تصویر بکشید** — با کوچکی مثل `docker pull docker.repo.mirrory.ir/library/nginx:latest` آزمایش کنید
3. **تفاوت را اندازه‌گیری کنید** — توجه کنید که چقدر سریع است
4. **جریان کار خود را پیکربندی کنید** — CI/CD، Kubernetes، یا راه‌اندازی شخصی خود را به‌روزرسانی کنید

به Docker سریع در زیرساخت شما خوش آمدید. بیایید ساختمان بر روی Docker در ایران را فوری کنیم.
